# SmartStock

ניהול מלאי, קופה, לקוחות ודוחות לעסקים קטנים. עובד בנייד ובמחשב, וניתן להתקנה כאפליקציה (PWA).

## מה יש במערכת

- **קופה** – חיפוש, סריקת ברקוד במצלמה או בסורק USB, עגלה עם כמויות, הנחה בש״ח או באחוזים, חישוב עודף, בחירת לקוח ואמצעי תשלום, קבלה בוואטסאפ או בהדפסה (80 מ״מ).
- **מלאי** – מוצרים, קטגוריות וספקים, רף מלאי נמוך, קליטת סחורה / ספירת מלאי / החזרה, יומן תנועות לכל מוצר, ייצוא לאקסל.
- **הזמנות** – היסטוריה עם סינון לפי תקופה, סטטוס ואמצעי תשלום; ביטול הזמנה מחזיר את המלאי.
- **לקוחות** – פרטים, היסטוריית קניות, התקשרות ווואטסאפ בלחיצה.
- **סקירה ודוחות** – מכירות היום והחודש, רווח, שווי מלאי, גרף 30 יום, ניתוח ABC, צפי גמר מלאי, מלאי שלא זז.
- **הגדרות** – פרטי העסק ולוגו לקבלות, מצב כהה.

## ארכיטקטורה

- **Frontend:** React 19 + Vite + TypeScript + Tailwind CSS 4, מתארח ב־Netlify.
- **Backend:** Supabase בלבד (Auth, Postgres, Storage). אין שרת ביניים.
- **אבטחה:** Row Level Security בכל הטבלאות – כל עסק רואה ומשנה רק את הנתונים שלו. המפתח שבקוד הוא ה־publishable key, שמיועד לדפדפן.
- **לוגיקה עסקית בדאטה בייס** (פונקציות `SECURITY INVOKER`, כך ש־RLS חל גם עליהן):
  - `create_order` – בודקת בעלות ומלאי, יוצרת הזמנה ופריטים, מורידה מלאי ורושמת ליומן, הכל בטרנזקציה אחת.
  - `cancel_order` – מבטלת ומחזירה מלאי.
  - `adjust_stock` – קליטה / ספירה / החזרה עם רישום ביומן.
  - `get_dashboard`, `get_reports` – כל החישובים לסקירה ולדוחות.

ה־SQL המלא נמצא ב־`supabase/migrations/`.

## פיתוח מקומי

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בדיקת טיפוסים + בנייה ל־dist/
```

הגדרות החיבור ל־Supabase נמצאות ב־`.env.development` / `.env.production`.

## פריסה ל־Netlify

`netlify.toml` מגדיר הכל: פקודת בנייה `npm run build`, תיקיית פרסום `dist`, Node 22, והפניית SPA.
כל push ל־`main` נפרס אוטומטית אם האתר מחובר לריפו.

### הגדרות חד־פעמיות ב־Supabase (Authentication → URL Configuration)

- **Site URL:** כתובת האתר ב־Netlify (למשל `https://smartstock.netlify.app`).
- **Redirect URLs:** להוסיף את אותה כתובת, כדי שקישורי אישור אימייל ואיפוס סיסמה יחזרו לאתר.
- מומלץ (אם זמין בתוכנית שלכם): להפעיל **Leaked password protection** בהגדרות הסיסמאות של Authentication.
